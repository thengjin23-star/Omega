# 氣動迴路編輯與模擬器

瀏覽器中的氣動工具，有兩個工作區（上方分頁切換）：

- **迴路圖**：拖拉氣動元件或**公司的產品**、用管線連接，按下播放即可看到模擬結果：有壓管線變色、閥門切換、
  速度控制閥改變氣缸速度、壓力錶顯示壓力。可以標註元件標號與型號、存成多份迴路、匯出 BOM。
  **自動化**：氣缸位置感測器（a0／a1）、氣控閥、滾輪閥、邏輯閥（OR／AND）、延時閥，
  輸入動作順序（例如 `A+ B+ B- A-`）即產生**程序控制**的步驟，自動／單步執行並畫出**位移－步驟圖**。
- **模組組立（3D）**：匯入公司產品的 STEP 檔，系統**自動從孔徑找出埠與螺紋規格**（亞德客型號直接判斷分類與名稱），把單一元件組成模組；
  沒有 3D 檔的零件可以產生**通用 3D**；也可以**用文字描述**模組，由 AI（Google Gemini）判斷零件、自動組裝；
  系統自動檢查螺紋／管徑搭配、建議轉接頭、產生 BOM。產品與埠會被記住，越用越完整。
  接上 **PU 管**、指定供氣口後，可以直接在 3D 上**模擬**（點電磁閥、看氣缸動作），也能一鍵**產生迴路圖**。
- **出圖**：模組一鍵產生**組立圖**（三視圖＋等角圖、外形尺寸、件號、零件表、對外接口表、標題欄），
  迴路圖產生含零件表的**迴路圖面**；下載 PDF（列印、給客戶）、DXF（AutoCAD 等 CAD）、SVG，
  模組另可匯出 **STEP 組立檔**（含 PU 管）給客戶的 CAD 使用。

兩個分頁共用同一份**產品庫**：在「模組組立」匯入的產品，切到「迴路圖」就能直接放進迴路模擬。
可安裝到手機主畫面（PWA），離線也能使用。

> 元件：氣源、過濾器、調壓閥、給油器、三點組合、壓力錶；5/2 手動閥、5/2 單電控／雙電控、5/3 中位封閉／排氣／加壓、
> 3/2 常閉／常開電磁閥、3/2 按鈕閥、2/2 電磁閥、5/2 單氣控／雙氣控、3/2 氣控閥、3/2 滾輪閥；
> 單向閥、速度控制閥（單向節流）、雙向節流閥、快速排氣閥；梭動閥（OR）、雙壓閥（AND）、氣動延時閥、壓力開關；
> 雙動／單動氣缸（位置感測器）；排氣口、消音器、塞頭。

## 快速開始

需要 Node.js 20 以上。

```bash
npm install
npm run dev       # 開發伺服器 http://localhost:5173
npm test          # 模擬引擎與註冊表的單元測試（Vitest）
npm run build     # 型別檢查 + 正式建置（含 service worker 與 manifest）
npm run preview   # 預覽正式建置 http://localhost:4173
npm run lint      # oxlint
node scripts/make-sample-parts.mjs   # 重新產生範例零件（public/samples/）
```

## 迴路圖：操作方式

**五秒驗收**：工具列「範例」→「單電控閥＋速度控制」→「播放」→ 點閥左邊的電磁線圈。

| 模式 | 可以做的事 |
|---|---|
| **編輯中**（重置後） | 從左側「元件」或「產品庫」拖拉到畫布（或**點一下**放到畫面中央的空位，觸控裝置請用這個方式）；從一個埠拖到另一個埠建立管線；選取後旋轉（`R`）、鏡射（`H`）、刪除（`Delete`） |
| **模擬中／已暫停** | 拓樸鎖定不可編輯；**點擊閥門或電磁線圈**切換（通電的線圈為黃色）；按鈕閥要**按住**；右側「模擬監看」可即時調整節流開度與設定壓力 |

- 管線顏色：**藍色＝有壓**、**淺灰＝排氣（通大氣）**、**深灰＝無壓（封閉）**；氣缸腔室有壓時填淺藍。
- 閥的排氣埠（EA／EB／R）**必須接到排氣口或消音器**才算通大氣（嚴格語意，符合實際接管）。未接的排氣埠會以琥珀色標示。
- 速度控制閥（單向節流）：1 → 2 自由流動、2 → 1 經節流；裝在氣缸口（2 接氣缸、1 接閥）即為排氣節流。
  氣缸速度取進氣側與排氣側較窄者，開度 25% 時約需 4 倍時間走完行程。
- 右側**屬性面板**（窄螢幕用畫布左上角的「屬性」開啟）：
  - 選取元件：元件類型（埠相同的可直接互換，例如單電控 ↔ 雙電控）、**標號**（自動編號 1A1、1V1、0Z1，可修改；標號位置可選上下左右）、
    **指定產品**（型號顯示在符號旁、列入 BOM）、參數（缸徑、行程、行程時間、節流開度、設定壓力…）、備註。
  - 沒有選取：電路名稱／客戶／備註、**檢查清單**（未接的埠、缺少氣源、標號重複、兩端快插管徑不同…，點一下跳到該元件）、
    **BOM**、埠代號顯示方式（字母 P A B 或 ISO 數字 1 4 2）。
- **檔案**選單：新電路、開啟…（這台裝置的電路清單）、儲存、另存新檔、匯入／匯出 `.pcir`（寄給同事或換裝置）、匯出 BOM（CSV）、
  **出圖**（PDF／DXF／SVG，見下方「圖面輸出」）。
  目前畫面也會自動存到瀏覽器，重新整理或離線開啟都還在。
- 快捷鍵：`Ctrl+Z`／`Ctrl+Y` 復原／重做、`Ctrl+C`／`Ctrl+V` 複製貼上、`Ctrl+D` 複製一份、`Ctrl+A` 全選、`Ctrl+S` 儲存、
  `R` 旋轉、`H` 鏡射、`Delete` 刪除。另可加入**文字註解**（雙擊編輯）。

### 自動化：訊號、氣控與邏輯元件、程序控制

**試用**：工具列「範例」→「程序控制：A+ B+ B− A−」→ 下方「程序控制」面板按「▶ 自動」，
兩支氣缸依序動作，右側畫出位移－步驟圖。另有「雙手按鈕安全迴路（AND）」與「滾輪閥自動往復（延時 2 秒）」兩個範例。

- **訊號名稱**（屬性面板的參數，新加入的元件自動編號、可修改）：
  - 電磁線圈接電氣輸出 **Y1、Y2…**，名稱標在線圈旁。接同一個輸出的線圈一起動作；模擬中點線圈就是切換該輸出（通電為黃色）。
  - 氣缸指定**代號 A、B…**，縮回端、伸出端的感測器為 **a0／a1**（b0／b1…），畫在活塞桿端，模擬中到達時亮綠燈。
  - 壓力開關輸出 **PS1…**（埠的壓力達到設定值時成立）。
- **氣控閥**：先導埠 **12／14**（ISO 5599）在符號兩端，接到先導埠的管線（控制管線）畫成**虛線**；
  單氣控為彈簧復歸，雙氣控為記憶型（兩邊都有壓時保持原閥位）。
- **滾輪閥**：指定「觸發位置」（例如 a1），氣缸到達時壓下滾輪。**氣動延時閥**：先導壓力持續「延遲時間」後才切換，模擬中可調整。
- **邏輯閥**：**梭動閥（OR）**任一入口有壓出口就有壓；**雙壓閥（AND）**兩個入口都有壓出口才有壓。
  **快速排氣閥**：P 洩壓時 A 直接由 R 排氣，加快氣缸回程。
- **程序控制**（工具列「程序」開關畫布下方的面板）：
  - 在「動作順序」輸入 `A+ B+ B- A-`（括號表示同時動作，例如 `A+ (B+ C+) A-`）按「產生步驟」：
    系統依氣缸代號找出驅動它的電磁閥與線圈，每一步設定輸出（單電控 A+ = Y1 ON、A- = Y1 OFF；雙電控另一側 OFF），
    轉移條件為對應的感測器（A+ 等 a1）。找不到氣缸、線圈沒有命名、閥不是電磁閥時會說明原因。
  - 步驟可以自己編：輸出（點一下切換 ON／OFF）、轉移條件（感測器、可取反）與計時（至少停留幾秒），上移／下移／刪除。
  - **自動**（可勾「連續循環」）、**單步**（每一步完成後停住，按單步才往下）、**停止**（再按自動從同一步繼續）、
    **復歸**（輸出全部 OFF、氣缸回到初始位置）。面板上方列出所有訊號的狀態燈。
  - 程序隨電路一起存檔（電路清單、`.pcir`、完整備份）。
- **位移－步驟圖**：模擬時自動記錄各氣缸的位置與輸出；「步驟」以最近一個程序循環畫出（每一步等寬），
  「時間」以秒為橫軸。出圖時勾「附位移－步驟圖」會加在第 2 張（含步驟表），PDF／DXF／SVG 都有。
- 檢查清單另外檢查：滾輪閥沒有觸發位置、氣缸代號重複、程序用到電路中沒有的輸出或感測器、沒有轉移條件的步驟。

### 選型計算：缸徑、耗氣量、閥與管徑

**試用**：範例「程序控制：A+ B+ B− A−」→ 點氣缸 1A1 → 屬性面板「選型」輸入負載 500 N →
按「套用 Ø50」；沒有選取元件時，右側「耗氣量」輸入每分鐘循環數。

- **缸徑**：輸入負載（N）、負載率（靜態夾持約 0.7、一般移動 0.5、高速或垂直上舉 0.3）與方向（伸出、縮回、兩方向）。
  - 需要的理論出力 = 負載 ÷ 負載率，建議缸徑為符合條件的最小標準缸徑（縮回扣除活塞桿面積）。
  - 缸徑不足時檢查清單會提醒；「套用」會改缸徑（可復原）。
- **計算壓力**：取氣缸埠的壓力，會反映調壓閥或三點組合的設定；也可以在「耗氣量」統一指定。
- **耗氣量**：每次伸出、縮回的耗氣量（NL，換算成大氣壓下的體積），含閥到氣缸之間的配管容積。
  - 迴路圖以建議管徑乘上配管長度（預設每條 1 m）估算配管容積；3D 模組用實際的 PU 管。
  - 每循環動作次數依程序計算：程序中沒有的氣缸以伸、縮各一次計算。
  - 每分鐘耗氣量 = 每循環 × 每分鐘循環數。跑完一個程序循環後會依循環時間建議次數，可以一鍵套用。
  - 峰值流量 = 同一步同時動作的氣缸所需流量的合計，是選空壓機與三點組合的參考。
- **閥與管徑**（參考值）：
  - 所需流量 Q（L/min，ANR）依活塞面積、行程與行程時間計算。
  - 閥的音速傳導 C ≥ Q ÷ (600 × (P + 0.1) × φ)，φ 為次音速修正；另列 S ≈ 5C（mm²）、Cv ≈ S ÷ 18。
  - 管徑取管內流速不超過 20 m/s、且不小於缸徑常用配管的 PU 管。
- **3D 模組**：屬性面板的「計算」分頁，負載記在這個模組的零件上，每分鐘循環數記在模組裡。
  由模組產生迴路圖時一併帶過去。
- **選型計算書**：出圖時勾「附選型計算書」，接在最後一張，含以下內容；迴路圖與 3D 模組都可以，PDF／DXF／SVG 都有。
  - 氣缸選型表、耗氣量與配管表。
  - 合計（每循環、每分鐘、峰值流量）。
  - 計算說明。

### 產品的氣動功能

產品要放進迴路圖，需要知道它是哪一種元件（例如 5/2 單電控閥）。系統依**分類、埠數與名稱**自動判斷：

| 產品 | 判斷為 | 埠對應 |
|---|---|---|
| 閥（5 口） | 5/2 單電控閥（名稱含「雙電控」「5/3 中位排氣」等會改判） | P/A/B/EA/EB，也認得 1/4/2/5/3、R1/R2 |
| 閥（3 口／2 口） | 3/2 常閉（名稱含「常開」「按鈕」會改判）／2/2 常閉 | 3 口時 A = 2、R = 3 |
| 氣缸 | 雙動（1 個埠為單動），並從型號帶入缸徑與行程（`CDJ2B16-50`、`Ø16 × 50`、`SC32X100`） | A、B |
| 速度控制閥 | 速度控制閥（單向節流） | 螺紋側 = 2（氣缸側）、快插側 = 1（閥側） |
| 消音器、三點組合（過濾／調壓／給油） | 對應元件 | IN/OUT |
| 閥（名稱含氣控、滾輪、梭動、雙壓、快速排氣、延時、壓力開關） | 對應的氣控閥、滾輪閥與邏輯元件 | 先導埠 12／14（也認得 Z、PILOT）、入口 X／Y（IN1／IN2） |
| 接頭、轉接頭 | 不畫在迴路圖（以管線表示） | 氣流直接通過 |
| 集裝座 | 不畫在迴路圖；3D 模擬時把裝在各站的閥接到共用通路 | 依埠名判斷 P、EA／EB（或 R）與各站出口 A1／B1、1A／1B…（A／B 在閥上的集裝座沒有各站出口） |

自動判斷的產品會標示「自動判斷」；在迴路圖的屬性面板或 3D「零件」頁的「氣動功能」可以確認或修改（類型、埠對應、參數），
兩個分頁與其他瀏覽器分頁會同步更新。

### 在手機上使用

- 部署到任何 **HTTPS** 靜態主機（`dist/` 資料夾）後，用手機瀏覽器開啟 →「加入主畫面」。
- Service worker 只在 HTTPS 或 `localhost` 下啟用。用 `npm run preview -- --host` 從區網 IP 在手機上測試時，應用程式可以操作，但不會註冊離線快取。


## 模組組立（3D）：操作方式

**試用**：上方切到「模組組立」→ 左側「安裝範例零件」→ 點選清單中的零件加入 → 點選一個零件的埠（箭頭或標籤），
再點選另一個零件的埠 → 看檢查結果 → 「鎖合」。

### 邊用邊建檔

1. 把要組合的 **STEP／IGES** 檔拖進畫面（或按「匯入 3D 檔」），可一次多個。
2. 系統以檔案內容的 SHA-256 判斷：**已經記住的檔案**直接沿用之前定義的埠；**新檔案**建立新產品（型號預設取檔名），
   並**自動找埠**（見下方）。
3. 自動找到的埠標示「自動」，看一下名稱與規格，對了按「全部確認」；不對的按「編輯」修改。
   漏掉的可以「＋ 新增埠」→ 點選零件上的**孔、凸柱或平面**：系統自動抓出位置、方向、直徑與公母，並依直徑建議規格
   （例如 Ø8.6 的孔 → Rc1/8 母；Ø9.73 的凸柱 → R1/8 公）。點建議或自己輸入後「儲存埠」，就記進產品庫。
4. 依序點兩個零件的埠，出現**連接檢查**：✓ 正確、! 注意、✕ 不相容、? 未設定規格（仍可先組起來，之後補規格會自動重新檢查）。
   不相容時會從產品庫找轉接頭並可一鍵插入；找不到就說明需要什麼規格的轉接頭。
5. 鎖合後後點的零件（連同已經和它接在一起的零件）會自動對位；螺紋可在「檢查」頁旋轉角度（例如調整彎頭方向），安裝面固定。
6. 「BOM」頁列出型號與數量，可下載 CSV（Excel 直接開啟）；產品填了廠牌、單價時一併列出小計與合計。

### 自動找埠

匯入 STEP 檔時，系統掃描模型上所有的圓柱面（孔與凸柱），自動定義埠；已經有的產品也可以在屬性面板按「**自動找埠**」。

- **哪些是埠**：只有一端開口的孔（孔口朝外）；貫穿的小孔（固定螺絲孔）、沉頭、釋放套筒、內部的通氣孔不算；
  公牙要在凸柱的尖端、根部有肩面（六角或本體）。氣缸的活塞桿、電磁閥的線圈不會被當成埠。
- **規格**：依孔徑或外徑對照螺紋表（CAD 的螺孔常畫成攻牙徑、小徑或大徑都認得），深度約 2 倍管徑的孔是快插口。
  PT 與 G 的孔徑一樣、從模型分不出來：預設 PT，型號寫明 G 或 NPT 時依型號。
- **名稱**：依位置命名——5 口閥 P／A／B／EA／EB、3 口閥 P／A／R、氣缸 A／B（遠離活塞桿的是 A）、
  三點組合 IN／OUT＋壓力錶、集裝座 A1…／B1…＋P＋EA／EB、接頭 1（外牙）／2（快插）。
- **型號規則（亞德客）**：檔名就是型號時，直接判斷分類、名稱、廠牌、系列與預期的規格，例如
  `4V210-08`（5/2 單電控電磁閥 PT1/4）、`PC6-01`（直通快插接頭 PT1/8 × Ø6）、`JSC6-01`、`BSL-01`、`SC32X100`、`GFR200-08`、`200M-4F`。
  沒有型號的檔名依形狀判斷（例如有活塞桿的是氣缸、1 個外牙＋1 個快插口的是接頭）。
- **不確定的孔**（例如大埠旁邊的 M5 小孔，可能是固定孔）不會自動加入，列在屬性面板，點一下就加入。
- 限制：集裝座站位、模組式三點組合的對接面這類**安裝面**無法從孔判斷，仍需手動設定一次；
  模型上沒有畫出孔（只有外形）、或螺紋畫成真實螺旋的檔案找不到埠。

### 通用 3D 零件

沒有原廠 3D 檔、或沒有型號的零件，產品庫的「**＋ 產生通用 3D 零件**」依種類與尺寸產生**示意模型**，埠已經定義好：
快插接頭（直通、彎頭、三通、管對管）、消音器、塞頭、轉接頭、L 型速度控制接頭、電磁閥、集裝座、氣缸、三點組合、壓力錶。
形狀是簡化的，但接口尺寸（螺紋外徑、孔徑、管徑）與配置接近實物，可以直接組裝、模擬、出示意圖與圖面。

- **電磁閥**（仿亞德客 4V／3V）：A、B 在上面，P 與排氣口（EA／EB，3 口閥為 R）在底面，線圈在一端（雙電控兩端）。
  大小分 100～400 系列（對應 4V100～4V400，依接管口自動選，也可以指定）。
  單獨使用時底面直接接接頭、消音器；底面也是裝集裝座的安裝面。
- **集裝座**（仿 100M～400M）：上面一排站位，閥橫跨在上面；內部有供氣與兩條排氣通道，P、EA、EB 從**端面**接出，兩側沒有出氣口。
  閥裝上集裝座後，閥底面的 P／排氣口由集裝座供氣、排氣（屬性面板顯示「裝在集裝座上」，搭配檢查不會當成沒接，3D 模擬與迴路圖的氣路也經集裝座）；
  A、B 的接頭接在閥上，供氣接頭與消音器接在集裝座端面。系列相同的閥與集裝座才裝得上。
- 匯入亞德客 4V／3V 閥的原廠 3D 檔時（型號認得），自動找埠也會在底面加上同樣的安裝面，可以直接裝到通用集裝座上。
產品的備註會寫明是通用 3D；之後拿到原廠檔可以再匯入替換。型號清單上找不到、或沒有 3D 檔的型號也會自動產生（見「依型號清單組裝」）。

### 越用越快：記住搭配

- 點選一個埠（標籤或右側「連接」）後，左側產品庫會列出**可接到這個埠的零件**：規格相容（✓ 正確、! 注意）的產品，
  以及**以前接過的零件排在最前面**（顯示「用過 N 次」）。點一下就加入並鎖合。
- 每次鎖合都會記下「這個埠接過哪個零件」與「這種規格的埠常接哪個零件」。
  選取零件後按「**自動配上常用零件**」，所有空著的埠一次接上最常用的接頭或消音器（只算一步復原）。
- 「**更換零件…**」：例如 Ø6 接頭換成 Ø8，原本的鎖合會對應到新產品同名或規格相容的埠；「**複製**」再加一個相同的零件。
- 「**套用到其他 N 個相同零件**」：先把一顆閥的接頭、消音器（含轉接頭＋接頭這類串接）接好，選取它後按這個按鈕，
  模組中其他相同型號的零件就在**同一個埠**接上相同的零件、相同角度（已經接了零件的埠不動，只算一步復原）。
  集裝座、底板那一側不算「接在閥上的零件」，不會被複製。
- 產品庫可依**類別**篩選、以型號／名稱／廠牌／**埠規格**（例如 `Rc1/8`）搜尋，並顯示 3D 縮圖。
- **只有型號的產品**：「＋ 新增產品（無 3D 檔）」先建型號（可直接放進迴路圖與 BOM），之後在產品庫點它即可附加 STEP 檔。
- 工具列「量測」：點兩個點（零件表面或埠的中心）顯示距離與 ΔX／ΔY／ΔZ；左下角顯示模組外形 W × D × H，可切換 3D 尺寸線。

### PU 管、供氣與 3D 模擬

**試用**：「安裝範例零件」→ 組好閥、速度控制閥、氣缸與接頭 → 工具列「接 PU 管」→ 依序點兩個快插接頭 →
選一個埠按「設為供氣口」→ 工具列「模擬」→ 點電磁閥。

- **PU 管**：工具列「接 PU 管」後，可以接的快插口以藍色標示，依序點兩個即接上；兩端管徑不同時會拒絕（需要變徑接頭）。
  管子沿兩端埠的方向畫成曲線，**長度自動估算**（曲線長加兩端插入長度，進位到 10 mm）；點選管子可修改長度、依目前位置重新估算或刪除。
  BOM 依管徑彙總條數與總長（m），圖面的視圖與零件表、STEP 組立檔都會包含 PU 管。
- **供氣口**：在「零件」頁選一個埠按「**設為供氣口**」（紅色標示），模擬時由這裡供氣（壓力可在模擬面板修改，預設 0.6 MPa）。
- **模擬**：工具列「模擬」依鎖合、接頭、PU 管與集裝座推出氣路：
  - **點電磁閥**切換（按鈕閥要按住），通電的閥以黃色標示；埠與 PU 管依壓力上色（藍＝有壓、淺灰＝排氣、深灰＝封閉）。
  - 氣缸的**可動件**（活塞桿）沿伸出方向移動，速度受速度控制閥影響；右上角面板可暫停、重置、結束，並列出提醒。
  - 模擬中模組鎖定，不能編輯或復原；結束模擬後恢復。
- **可動件**：3D「零件」頁的「氣動功能」可勾選氣缸模型中屬於可動件的零件與伸出方向；沒有設定時依零件名稱（ROD、PISTON、活塞、桿…）判斷，
  模型沒有分開的可動零件時，改為顯示伸出百分比。
- **氣路檢查**（「檢查」頁）：還沒有供氣口、底板式閥沒有裝在集裝座上、零件沒有設定氣動功能、埠沒有接（模擬時視為封閉）、
  排氣口直接排大氣（建議加裝消音器）；點一下選取該零件。
- **產生迴路圖**：工具列「產生迴路圖」依模組的氣路畫出迴路圖，並切到「迴路圖」分頁：
  - 接頭與集裝座以管線表示；由上到下依序是氣缸、速度控制閥、閥、消音器、氣源處理與氣源，速度控制閥對齊氣缸的埠。
  - 自動帶入 ISO 1219-2 標號（1A1、1V1、1V2…、0Z1）與型號，可以直接播放模擬、出圖或存檔。
  - 模組的訊號名稱與程序一起帶過去，迴路圖分頁可以直接按「自動」執行。
  - 目前的迴路圖有未儲存的變更時會先確認。

### 3D 模組執行程序

**試用**：組好閥、速度控制閥、氣缸與 PU 管並設好供氣口 → 工具列「程序」→ 輸入 `A+ A-` 按「產生步驟」→「▶ 自動」。

- **和迴路圖同一套程序控制**：畫面下方的程序面板可以由動作順序產生步驟、自己編步驟，自動、單步、停止、復歸、連續循環，
  右側畫出位移－步驟圖（或位移－時間圖）。還沒開始模擬時按「自動」會直接開始模擬。
- **訊號名稱**：打開程序或開始模擬時，依氣路自動指定氣缸代號（A、B…，感測器 a0／a1）與電磁線圈的輸出（Y1、Y2…），
  順序與「產生迴路圖」的欄位相同。名稱記在這個模組的零件上，可在「零件」頁的「訊號（程序控制）」修改（可復原）；
  選「自動」會重新指定。滾輪閥的觸發位置也在這裡設定。
- **3D 上的訊號燈**：模擬中氣缸上方顯示代號與 a0／a1 燈號，電磁閥顯示線圈的輸出，通電時亮。
- 程序存在模組裡（`.pmod`、完整備份都包含）；複製零件時會複製負載等參數，但不複製訊號名稱。

### 規格寫法

| 種類 | 寫法範例 | 說明 |
|---|---|---|
| 錐管螺紋 | `PT1/4 公`、`PT1/4 母`、`R1/8`、`Rc1/8` | PT 依公母轉成 R（公）／Rc（母） |
| 平行管螺紋 | `PF1/8 公`、`G1/4 母`、`PS1/4` | PF = G；PS = Rp（平行母牙） |
| NPT | `NPT1/8 公`、`1/4NPT 母` | 牙角 60°，與 PT 不相容 |
| 公制／統一螺紋 | `M5`、`M6x0.75`、`10-32UNF` | 省略牙距時為粗牙 |
| 快插管徑 | `Ø6 快插`、`Ø6 插管`、`Ø1/4" 快插` | 快插口配插管端，管徑須相同 |
| 安裝面 | 在「安裝面」分頁輸入名稱，例如 `SY3000 閥座面` | 元件側配底座側、對接面配對接面；用於集裝座、三點組合 |

公／母也可寫成外牙／內牙或 male／female；沒寫時依模型判斷（孔 = 母、凸柱 = 公）。

### 搭配檢查（節錄）

| 組合 | 結果 |
|---|---|
| R 公 ↔ Rc 母、R 公 ↔ Rp 母、G ↔ G | ✓（附密封方式提醒） |
| R 公 ↔ G 母、G 公 ↔ Rc 母 | ! 可鎖入但密封不可靠 |
| NPT ↔ PT（R／Rc／G） | ✕ 說明牙角 55°／60° 與牙數差異 |
| M5 ↔ 10-32UNF | ✕ 外觀相近但不可混用 |
| 尺寸不同、公對公、母對母、公制與英制管徑 | ✕ 並描述需要的轉接頭 |

## 圖面輸出

**示意圖（型號標註圖）**：模組工具列「示意圖」選單。給研發申請、報價附圖用：著色的 3D 圖旁標上每個零件的**型號**，
箭頭指向零件；**同型號只寫一次、拉多條箭頭**。

**依敘述產生（AI）**：連型號都不用知道，用文字描述要的模組，例如
「4 位電磁閥集裝座，5/2 單電控，A、B 口接 6mm 快插，P 口接 8mm 快插，排氣加消音器；另外一支 Ø32 行程 100 的氣缸，兩個口接 6mm 速度控制接頭」。

- AI（Google Gemini，需在「設定」貼上金鑰）判斷要用哪些零件、幾個、接在哪；台灣慣用語（1分＝1/8"、2分＝1/4"、PT／PF）也看得懂。
- 產品庫有合適的產品就用原廠 3D（AI 只能選產品庫裡真的有的型號），沒有的產生**通用 3D**。
- 結果先列成表格讓你確認：可以改數量、移除；AI 做的假設（例如「沒說牙型，假設 PT」）與沒指定而補上的尺寸都會列出來。
- 按「建立零件並組裝」→ 自動組裝、搭配檢查（與下面的型號清單相同）→ 產生示意圖。

**依型號清單組裝並產生**：不用自己組，輸入要用的型號與數量，系統自動在 3D 組好模組、檢查搭配，再產生示意圖。
產品庫沒有、或沒有 3D 檔的型號（預設勾選「自動產生通用 3D」）：亞德客型號依型號規則、其他廠牌由 AI 判斷規格後產生通用 3D。

```
DEMO-MANIFOLD-4
DEMO-VALVE-VB ×4
DEMO-FITTING-R18-D6 ×4 → A          ← 指定接在 A 埠（集裝座的 A1～A4 都算）
DEMO-FITTING-R18-D4 ×4 → B
DEMO-BUSH-R14-RC18 → P
DEMO-FITTING-R18-D6 → DEMO-BUSH-R14-RC18   ← 指定接在轉接頭上
DEMO-SILENCER-R18 ×2                 ← 沒指定：自動接到排氣口
```

- **清單寫法**：一行一個型號，數量寫「×4」「x 4」「4 個」都可以（沒寫就是 1 個）；「、」「；」可以一行寫多個；
  「#」後面是備註；也可以直接從 Excel 複製「型號、數量」欄位貼上（表頭會略過）。型號不分大小寫、全形半形，
  `-`、`/` 等符號寫錯也找得到。左邊輸入時，右邊即時列出每一行對應的產品；找不到的型號會建議相近的型號，按「換成」即可。
- **指定埠**：「→ A、B」「@ EA」「接在 型號 的 P」。沒指定時依**埠的規格**（螺紋、快插管徑、集裝座的安裝面）、
  **以前的搭配記錄**與**埠的用途**（排氣口優先接消音器）自動決定。集裝座（或能接最多零件的產品）當底座，
  閥先裝到站位，轉接頭接上後接頭會接在轉接頭上；接不上主體的零件（例如氣缸＋速度控制閥）另起一組、並排放置。
- **結果與提醒**：列出找不到的型號、沒有 3D 檔的產品，以及**沒接上的零件與原因**（例如「規格相容的埠都接滿了」
  「模組上沒有規格相容的空埠」，並建議加哪個轉接頭）。
- **搭配檢查**（組裝對話框與示意圖上方都有）：
  - ✕ 搭配不對：鎖合兩端的規格不合（例如 NPT 接 Rc），列出可用的轉接頭。
  - ! 要注意：集裝座站位空著（加盲板）、螺紋口沒接（排氣口提醒加消音器，其他提醒加接頭或塞頭），
    列出可以接的零件（以前用過的排前面），**點一下就補上**；「依建議補上」一次補齊。
  - 快插口空著是正常的（之後接 PU 管），彙總成一行。
- 清單記在模組裡：示意圖對話框的「修改型號清單」回到清單，改完按「重新組裝」（可以復原）。
  目前的模組如果是手動組的，會保留不動、另外開一個新模組。

- **視角**：「目前 3D 畫面的角度」（先在 3D 畫面轉到想要的角度再打開）、六個正面方向（例如從上方看閥島）或等角。
  圖面為正交投影（沒有透視變形）。
- **外觀**：零件顏色依 3D 檔或統一灰色（型錄風格），可加零件輪廓線；PU 管一併畫出並標註管徑。
- **標註**：自動找出每個零件**看得到的位置**當箭頭落點（被擋住的零件不拉箭頭，列在附註），型號依位置排在上下左右，
  彼此不重疊。標註內容可選「型號」「型號＋數量（×4）」「型號＋名稱」；每個型號可以改文字（例如換成客戶的料號）或不標註；
  **拖曳圖上的型號**可移動位置。這些設定記在模組裡，下次沿用。
- **輸出**：下載 PNG（2 倍解析度，可加模組名稱、客戶、日期）、**複製圖片**（直接貼到 Email、LINE、Word），
  或下載 PDF（A3／A4 圖框與標題欄，型號與箭頭為向量，3D 圖為點陣圖）。沒有 3D 檔的產品列在附註。

**模組組立圖**：模組工具列「產生圖面」，右側即時預覽，調整後下載 PDF、DXF 或 SVG。

- **視圖**：前視圖、俯視圖、側視圖（第三角法為右側視圖、第一角法為左側視圖）依投影法排列並對齊，另加等角圖。
  「前視圖方向」可選模組的哪一側當正面（±X、±Y、±Z）。線條由 3D 網格直接計算：特徵邊（面與面的交界）與輪廓線，
  以深度緩衝判斷可見與隱藏（隱藏線以虛線表示，可關閉；等角圖不畫隱藏線）。
- **尺寸與比例**：自動標註外形寬、深、高；比例自動取放得下的最大標準比例（10:1～1:100，含 1:1.5、1:2.5 等 CNS 比例），
  等角圖放在剩下的空白中，比例不大於三視圖（不同時會標示在圖名旁）。
- **件號與零件表**：等角圖外圍依方位排列件號氣球（引線不交叉），零件表在標題欄上方、項次由下往上（ISO 7573）；
  沒有 3D 檔的產品只列在零件表。PU 管畫在視圖中，零件表依管徑列出條數與總長。
- **對外接口**：模組中沒有接上的埠，以六角形記號標在埠口正對的視圖，並列出「對外接口表」（零件、埠、規格），
  方便客戶配管。
- **標題欄**（CNS 風格）：公司名稱與標誌、圖名、客戶、圖號、版次、張數、日期、繪圖者、比例、單位、投影法符號、審核、核准。
  圖號、版次、備註（技術要求）與各項選項會記在模組裡，下次沿用。零件太多時，零件表後段、對外接口表與備註移到第 2 張（續頁）。
- **格式**：
  - PDF：頁面即圖紙大小（A3／A4 橫式），中文字型（Noto Sans TC）只嵌入用到的字，通常 50～300 KB，文字可搜尋、複製。
  - DXF：AutoCAD R12 格式，幾乎所有 CAD 都能開。**視圖為 1:1 實際尺寸**，圖框與文字依比例放大，在 CAD 裡量到的就是實際尺寸；
    圖層 OUTLINE／HIDDEN／CENTER／DIM／TEXT／TITLE／FRAME／BALLOON，中文字以 `\U+XXXX` 寫入，文字樣式的字型檔名在「設定」修改（預設 msjh.ttc）。
  - SVG：單位 mm，可直接插入文件。

**STEP 組立檔**：模組工具列「匯出 STEP」。每個零件的原始 STEP 依組立位置轉換後寫成一個檔（AP242、mm），
零件以「項次_型號」命名並保留顏色，可在 SolidWorks、Inventor、Fusion 360 等開啟。原始檔為 IGES 的零件無法寫入（會列出略過的零件）。
PU 管沿畫面上的曲線掃出圓管實體（外徑、內徑依常用規格，例如 Ø6 × 4），以「項次_PU 管 Ø6_1」命名。

**迴路圖面**：迴路圖「檔案 → 出圖」。符號與管線與畫面相同（黑白線條，控制管線為虛線），加上標號與型號、分歧點、文字註解、零件表（標號彙總）、
電路備註與標題欄；迴路圖不依比例，自動縮放到圖紙的空白區。模擬過的電路可以附上第 2 張「位移－步驟圖」（最近一個完整的程序循環與步驟表）。

第一次輸出 PDF 會下載中文字型（約 7 MB）、第一次匯出 STEP 會下載 STEP 處理元件（約 23 MB），之後由 service worker 快取，離線也能使用。

### 限制

- 原廠 3D 檔通常沒有螺紋資訊，每個埠的規格需要人工確認一次（系統會依直徑建議）。
- SolidWorks 等原生檔需先匯出成 STEP；目前不支援 STL。
- 一個 STEP 檔視為一個產品。R 錐管螺紋實際旋入後肩面與孔口可能有 1～3 mm 間隙，畫面上以貼齊表示。

## 模組組立的設計

- **埠的座標系**（零件座標，mm）：母牙原點在孔口、公牙原點在螺紋根部（肩面），`axis` 朝外，`ref` 為旋轉基準。
- **點選定義埠**：取點選三角形所屬的 B-rep 面；法向量共變異矩陣的最小特徵向量即圓柱軸，圓擬合求直徑，
  法向量朝向軸線為孔、背向為凸柱；在靠近孔壁處沿軸向發射射線（BVH 加速）判斷哪一端是開口。
- **鎖合**：`W子 = W父 · F父埠 · Rz(θ) · Rx(π) · F子埠⁻¹`（兩埠原點重合、軸線相反）。鎖合關係構成樹；
  後點的零件若已在另一個群組中，會把該群組的根換成它（位置不變）再整組移過來。
- 模組只引用產品，修改產品的埠規格後，所有用到它的模組會自動重新計算位置與重新檢查。
- **模組 → 氣路**：鎖合、接頭（氣流直接通過）與 PU 管把埠連成「網路」（union-find）；有氣動功能的零件成為迴路元件，
  功能埠依「埠對應」接到網路。集裝座依埠名找出共用的 P／EA／EB 與各站的 A／B 出口，裝在某一站的底板式閥，
  其 P／EA／EB 接到共用通路、A／B 接到該站的出口；閥本身有 P／排氣口、底面被安裝面封住時（例如亞德客 4V），
  那些埠接到共用通路，A／B 用閥上的埠。供氣口所在的網路接上氣源；只接到排氣埠的網路視為通大氣
  （並提醒加裝消音器）；其餘空著的埠視為封閉。推出的迴路交給同一個模擬引擎，3D 模擬與「產生迴路圖」共用這份結果。

## 模擬引擎

不做流體力學計算，採「邏輯走訪＋簡化物理」：

1. 每個元件定義自己的埠，以及依目前狀態決定的**內部通路**（例如 5/2 閥位置 0：P→A、B→EB）。
   通路可以是雙向全開的 `[a, b]`，或 `{ from, to, oneWay, capacity, maxPressure }`：單向（單向閥）、
   節流（capacity 0–1）、限壓（調壓閥出口）。
2. `solve()`：以「埠」為節點、「管線（雙向）＋內部通路」為邊建立有向圖。
   從氣源往前走得到**有壓**、在反向圖上從排氣口走得到**能排氣**；有壓優先。
   另以最寬路徑（沿途最窄處取最大）算出每個埠的**供氣能力**、**排氣能力**與**壓力值**（氣源壓力經調壓閥限制）。
3. `step(circuit, state, dt)`：純函式。先 solve，依結果呼叫各元件的 `update`
   （雙動氣缸：A 有壓且 B 排氣 → 伸出，速度 = min(進氣能力, 排氣能力) ÷ 全開行程時間；單動氣缸排氣時彈簧復歸），
   再 solve 一次讓回傳的壓力與回傳的元件狀態一致。
4. `interact(circuit, state, nodeId, reg, action)`：使用者操作，例如 `'toggle'`（點本體）、`'coil:l'`（點左側線圈）、
   `'press'`／`'release'`（按鈕閥）。有命名的線圈被點擊時，切換的是電氣輸出（`manualOutputs`），接同一個輸出的線圈一起動作。
5. **訊號**：元件以 `getSignals` 產生訊號（氣缸的 a0／a1、壓力開關）；`step` 在每幀開始時收集訊號（加上電氣輸出 Y1…），
   交給各元件的 `update`（電磁線圈依輸出、滾輪閥依感測器、氣控閥依先導埠壓力、延時閥累計時間）。
   `setOutputs` 設定輸出並立即以 `dt = 0` 讓元件切換。
6. **邏輯元件**（梭動閥、雙壓閥、快速排氣閥）以 `portPaths` 依埠的壓力決定通路；`solve` 以上一幀的狀態為起始猜測，
   反覆計算到通路不再改變，因此邏輯閥的輸出在同一幀內就正確，不會讓下游的記憶型氣控閥誤動作。
7. **程序控制**（`sequence.ts`）也是純函式：`tickSequence` 每幀累計時間，轉移條件成立就進入下一步並回傳要設定的輸出；
   `planSequence` 由動作順序沿管線與流量控制元件找到驅動每支氣缸的電磁閥與線圈。
8. 元件參數（缸徑、行程時間、節流開度、設定壓力、訊號名稱…）放在節點上，引擎呼叫時會套用預設值與範圍（`resolveParams`）。
9. 畫面以 `requestAnimationFrame` 驅動，單幀 `dt` 上限 0.05 秒，避免切換分頁回來時活塞瞬移。

效能上，React Flow 只持有拓樸；每個節點／管線以 Zustand selector 只訂閱自己的那一小片模擬狀態
（壓力狀態刻意設計為字串 primitive），因此每幀只有真正變化的元件會重繪。

## 如何新增元件

**方向控制閥**只要在 `src/engine/components/valves.ts` 的 `VALVE_SPECS` 加一筆規格（方格內的通道、靜止位、左右操作方式），
行為與 ISO 符號都由同一份規格產生：

```ts
valve32Button: {
  type: 'valve32Button',
  label: '3/2 按鈕閥（常閉）',
  portSet: 3,                          // P A R
  boxes: [[['P', 'A']], [['A', 'R']]], // 由左到右的方格：作動位、靜止位
  rest: 1,
  left: ['button'],
  right: ['spring'],
  mode: 'button',                      // 按住作動、放開復歸
},
```

**其他元件**：

1. **行為**：在 `src/engine/components/` 以 `defineComponent` 定義埠、參數、內部通路、`update`／`onInteract`，
   需要時再加 `getSignals`（產生訊號）、`portPaths`（依埠壓力決定的通路）、`manualOutputs`（手動操作帶動的電氣輸出），
   並加入 `src/engine/components/index.ts` 的 `builtinComponents`。
2. **外觀**：在 `src/components/symbols/` 新增 `*Symbol.tsx`，匯出 `{ width, height, ports, Symbol }`，
   並加入 `symbolRegistry.ts`。埠座標以未旋轉的符號為準，旋轉與鏡射由節點統一處理。
3. `npm test`：`symbolRegistry.test.ts` 會檢查兩份註冊表的 type 與埠是否一致；`registry.test.ts` 檢查結構。

引擎本身（solve／step）不需要修改；`registry.test.ts` 內有一個以註冊表外的 3/2 閥＋單動氣缸示範擴充的測試。
